## 开发与终端

- **编辑器**
  - **VS Code**：通用、插件多
  - **Cursor**：AI 辅助编辑
  - **Zed**：轻量高性能编辑器
- **AI 编程与助手**
  - **Claude Code**：命令行 AI 编程助手
  - **Codex / ChatGPT**：代码生成与对话助手
  - **DeepSeek Harness**：DeepSeek 编程与 Agent 框架
  - **CC Switch**：Claude Code / Codex 配置与模型切换工具
- **终端**
  - **iTerm2**（macOS）
- **Shell**
  - **fish**：交互补全友好
  - **bash**：脚本与兼容
- **会话复用**
  - **tmux**：终端多窗口与会话保持
  - **screen**：经典终端会话复用

## 系统与日常效率

- **启动与切换**
  - **Raycast**（macOS）：本地搜索、启动应用
- **截图与图像**
  - **Snipaste**：截图贴图
  - **GIMP**：图像处理
- **PDF**
  - **PDFgear**：阅读与简单编辑
- **副屏 / 手写**
  - **Weylus**：平板作副屏或手写板
- **启动盘与镜像**
  - **Ventoy**：多系统 U 盘，拖入 ISO 即用
  - **dd**：命令行写盘、镜像
  - **UltraISO**：图形化 ISO 编辑刻录

## 科研与知识管理

- **分子可视化**
  - **PyMOL**：蛋白 PDB 可视化
  - **Avogadro**：分子建模（含 SDF 等）
- **文献与邮件**
  - **Zotero**：文献管理与引用
  - **Thunderbird**：多账户邮件
- **笔记与电子书**
  - **Obsidian**：Markdown 知识库
  - **Calibre**：电子书管理与转换

## 网络与文件传输

- **代理与穿透**
  - **Clash Verge**：规则代理客户端
  - **frp**：反向代理内网穿透
- **虚拟局域网（组网）**
  - **Netbird**（开源）：WireGuard 系，支持 P2P
  - **Tailscale**（闭源）：WireGuard 系，支持 P2P
  - **ZeroTier**：虚拟局域网
  - **OpenVPN**：传统虚拟局域网
- **同步与下载**
  - **rsync**：增量文件同步
  - **scp**：基于 SSH 的文件传输
  - **FreeFileSync**：图形化目录对比与同步
  - **axel**：命令行多线程下载
  - **aria2**：批量与脚本化下载
