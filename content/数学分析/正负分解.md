## 定义

- 设 $f: X \to [-\infty, \infty]$ 是定义在集合 $X$ 上的广义实值函数。正部 (Positive Part) $f^+$ 定义为：$$f^+(x) = \max\{f(x), 0\}$$负部 (Negative Part) $f^-$ 定义为：$$f^-(x) = \max\{-f(x), 0\}$$

## 性质

1. 原函数分解：$$f = f^+ - f^-$$
2. 绝对值分解：$$|f| = f^+ + f^-$$
3. 单调性： 如果 $f \le g$，则 $f^+ \le g^+$ 且 $f^- \ge g^-$。
4. 复合函数：
   $$(g \circ f)^+ = g^+ \circ f$$
   $$(g \circ f)^- = g^- \circ f$$
5. (1) $(f+g)^+ \leqslant f^+ + g^+$, $(f+g)^- \leqslant f^- + g^-$;
   (2) $(fg)^+ = f^+ g^+ + f^- g^-$, $(fg)^- = f^+ g^- + f^- g^+$;
   (3) 当 $c \geqslant 0$ 时, $(cf)^+ = cf^+$, $(cf)^- = cf^-$;
   (4) 当 $c < 0$ 时, $(cf)^+ = -cf^-$, $(cf)^- = -cf^+$.

## 证明

### **命题 正负分解的移项等式**

设 $f, g: X \to \overline{\mathbb{R}}$。若对任意 $x \in X$，$f(x) + g(x)$ 均良定义（即不出现 $\infty - \infty$ 型不定式），记 $s = f + g$。则其正部与负部满足如下逐点恒等式：

$$s^+ + f^- + g^- = s^- + f^+ + g^+$$

该等式两端每一项均属于 $[0, +\infty]$，式中仅涉及非负项的加法，在扩展实数系下完全良定义。

#### **证明**

固定任意 $x \in X$，记 $a = f(x),\, b = g(x),\, c = a + b$。按 $c$ 的取值分三种情况验证：

**情形 1：$a, b \in \mathbb{R}$（均为有限实数）。**

此时 $c \in \mathbb{R}$，所有正负部均为有限非负实数。由 $c = a + b$ 及正负分解 $c = c^+ - c^-$、$a = a^+ - a^-$、$b = b^+ - b^-$ 得

$$c^+ - c^- = a^+ - a^- + b^+ - b^-.$$

在 $\mathbb{R}$ 中直接移项（将 $c^- + a^- + b^-$ 加到等式两端）即得

$$c^+ + a^- + b^- = c^- + a^+ + b^+.$$

**情形 2：$c = +\infty$。**

由 $a + b$ 良定义知 $\min\{a, b\} > -\infty$，故 $a, b$ 中至少有一个为 $+\infty$。

不妨设 $a = +\infty$，则 $a^+ = +\infty$，$a^- = 0$，$c^+ = +\infty$，$c^- = 0$。

由于 $b \neq -\infty$，$b^- \in [0, +\infty)$（若 $b = +\infty$ 则 $b^- = 0$）。代入：

$$
\begin{aligned}
\text{左端} &= c^+ + a^- + b^- = +\infty + 0 + b^- = +\infty, \\
\text{右端} &= c^- + a^+ + b^+ = 0 + (+\infty) + b^+ = +\infty.
\end{aligned}
$$

两端相等。

**情形 3：$c = -\infty$。**

由良定义知 $\max\{a, b\} < +\infty$，故 $a, b$ 中至少有一个为 $-\infty$。

不妨设 $a = -\infty$，则 $a^+ = 0$，$a^- = +\infty$，$c^+ = 0$，$c^- = +\infty$。

由于 $b \neq +\infty$，$b^+ \in [0, +\infty)$。代入：

$$
\begin{aligned}
\text{左端} &= c^+ + a^- + b^- = 0 + (+\infty) + b^- = +\infty, \\
\text{右端} &= c^- + a^+ + b^+ = +\infty + 0 + b^+ = +\infty.
\end{aligned}
$$

两端相等。

---

三种情形覆盖所有可能，等式逐点成立。$\square$
