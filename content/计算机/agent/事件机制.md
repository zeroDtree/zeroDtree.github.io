## 命名规则

1. **格式**：`domain[.subdomain…].suffix`。全小写、点分；**末段必须是已登记后缀**；总长 2～4 段（含后缀）。
2. **域（domain）**：运行时实体边界 — `runtime`、`session`、`user`、`assistant`、`tool`、`permission`、`notification`、`agent`、`task`、`context`、`config`、`workspace`、`file`、`model`。
3. **子域（subdomain）**：同一域内的名词短语，用单个紧凑单词（如 `setup`、`turn`、`execution`、`compaction`、`cwd`）。**禁止**段内 `snake_case`（例如 `working_directory` 应写成 `cwd`）。
4. **生命周期终态**：有明确起点的操作发 `*.started` → `*.ended`（`ended` 必达）。成功、失败、取消等原因写在 payload，例如 `outcome: "success" | "failure" | "cancelled"`，**不**再单独发 `succeeded` / `failed` / `completed` 事件名。
5. **单次信号**：无 `started` 的纯状态变更（如 `config.changed`）只发一次。
6. **`interrupted` 与 `cancelled`**：`user.interrupted` 表示用户主动打断当前执行（可在 payload 中带 `outcome: "cancelled"`）。后缀 `cancelled` 用于系统或流程在未完成时主动取消（如 `tool.execution.cancelled`），不用于描述用户中断动作本身。

有 `started` 的流程在 payload 中可带 `outcome`；跨系统日志若需成败维度，使用字段名 `outcome`，不要扩展事件后缀表。

## 后缀

| 类别       | 后缀        | 含义                         |
| ---------- | ----------- | ---------------------------- |
| 生命周期   | `started`   | 操作或流程开始               |
| 生命周期   | `resumed`   | 暂停、挂起后恢复             |
| 生命周期   | `ended`     | 流程结束（不要求成功）       |
| 生命周期   | `created`   | 实体被创建                   |
| 用户交互   | `submitted` | 用户提交输入                 |
| 用户交互   | `interrupted` | 用户打断当前执行           |
| 请求与控制 | `requested` | 发起请求，尚未执行           |
| 请求与控制 | `cancelled` | 系统或流程取消，未正常结束   |
| 请求与控制 | `approved`  | 操作被批准                   |
| 策略结果   | `denied`    | 策略或权限拒绝               |
| 事件触发   | `triggered` | 条件或触发机制激活           |
| 状态变化   | `changed`   | 配置或状态改变               |
| 资源       | `added`     | 向集合中新增一项             |
| 资源加载   | `loaded`    | 配置、指令、资源就绪         |
| 出站       | `sent`      | 通知或消息已发出             |
| 入站       | `received`  | 通知或消息已接收             |

## 事件清单

### 运行时

- `runtime.setup.started` — 运行时初始化开始
- `runtime.setup.ended` — 运行时初始化结束
- `runtime.destroy.started` — 运行时销毁开始
- `runtime.destroy.ended` — 运行时销毁结束

### 会话与初始化

- `session.started` — 新会话开始
- `session.resumed` — 已有会话恢复
- `session.ended` — 会话结束

### 用户输入

- `user.prompt.submitted` — 用户提交 Prompt
- `user.interrupted` — 用户中断执行

### 助手响应

- `assistant.turn.started` — 助手开始当前响应轮次
- `assistant.turn.resumed` — 助手恢复当前响应轮次
- `assistant.turn.ended` — 助手完成当前响应轮次

### 工具执行与分发

- `tool.execution.started` — 工具开始执行
- `tool.execution.ended` — 工具执行结束（成败见 payload `outcome`）
- `tool.dispatch.started` — 策略准许，调用进入分发

### 权限

- `permission.requested` — 工具调用请求权限或用户确认
- `permission.denied` — 权限或策略拒绝（含自动拒绝）
- `permission.approved` — 权限或用户确认通过

### 通知

- `notification.sent` — Agent 发送通知

### Agent 与任务

- `agent.started` — 子 Agent 开始执行
- `agent.ended` — 子 Agent 执行结束
- `task.created` — 创建任务
- `task.ended` — 任务结束

### 上下文管理

- `context.compaction.started` — 上下文压缩开始
- `context.compaction.ended` — 上下文压缩结束

### 环境与配置

- `config.changed` — 配置发生变化
- `workspace.cwd.changed` — 当前工作目录发生变化
- `workspace.directory.added` — 新增工作目录
- `file.changed` — 被监控文件发生变化

### 模型切换

- `model.switch.requested` — 发起模型切换请求
- `model.changed` — 当前使用的模型发生变化
