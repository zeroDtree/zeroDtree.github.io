## 逻辑权限

逻辑权限在 capability 之上按路径收紧 agent 的资源访问，应编译进 sandbox 的运行时配置，也可选地进入提示词系统。

| 逻辑权限 | 所需 capability | 路径根 |
| --- | --- | --- |
| `rw_plan` | `rw_plan` | 计划、任务清单、ADR |
| `rw_source` | `rw` | 任务授权的源码路径 |
| `rw_tests` | `rw` | 测试与夹具 |
| `rw_docs` | `rw` | 文档 |
| `rw_artifacts` | `rw` | 派生产物 |
| `rw_scratch` | `rw` | 当前任务的临时目录 |

```yaml
permission:
  resource_type: filesystem
  capability: rw
  operations: [read, create, write, overwrite]
  allow:
    - /workspace/src
  deny:
    - .env
    - /workspace/secrets
    - /workspace/production
  symlink_policy: deny_escape
```

这是 `rw_source`。`rw_plan`、`rw_tests`、`rw_docs`、`rw_artifacts`、`rw_scratch` 用同一组字段，只改 `capability` 和路径。委派给出若干条这样的权限。
