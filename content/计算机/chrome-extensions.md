| 扩展                   | 简介                                               |
| ---------------------- | -------------------------------------------------- |
| Adblock Plus           | 广告拦截，覆盖 YouTube 等常见站点                  |
| CCFrank                | 在 dblp、Google Scholar 等页面显示 CCF 推荐等级    |
| ChatGPT to Markdown    | 将 ChatGPT 对话导出为 Markdown / Obsidian / Notion |
| ChatGPT to PDF         | 将 ChatGPT 对话导出为排版好的 PDF                  |
| DeepSeek Chat Exporter | 导出 DeepSeek 对话（PDF / HTML / Markdown 等）     |
| FoxyProxy              | 代理管理与切换                                     |
| Ghelper                | 科学上网辅助，面向开发与跨境访问                   |
| Google Docs Offline    | 离线编辑 Google 文档 / 表格 / 幻灯片               |
| IE Tab                 | 在 Chrome 内用 IE 内核打开页面（遗留 ActiveX 等）  |
| Proxy SwitchyOmega 3   | 多代理快速切换（ZeroOmega）                        |
| Vimium                 | Vim 风格键盘浏览与页面控制                         |
| Zotero Connector       | 从网页一键保存文献到 Zotero                        |
