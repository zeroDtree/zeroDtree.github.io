台式机后面有两组视频口。和 USB、网口、音频口排在一起的是主板口，走 CPU 核显。独立显卡挡板上横着的一排是独显口。两组口各走各的输出。

## 主板 HDMI 不亮

主板 HDMI 没有画面，常见是下面几种：

- CPU 没有核显，主板上的 HDMI 没有信号。
- 装了独立显卡后，BIOS 默认只用独显，核显输出关掉。
- CPU 有核显，但 BIOS 里没有打开 `iGPU`、`Integrated Graphics` 或 `Multi-Monitor`。

## 接到 NVIDIA 独显

能亮的口在显卡挡板上，走的是 NVIDIA 独显。独显的画面从显卡自己的 HDMI 或 DP 送出。主板上的 HDMI 接的是 CPU 核显。

显示器接在显卡上。显卡有 DP 时用 DP，没有 DP 时用 HDMI。

要让主板口也出画面，CPU 需要带核显，并在 BIOS 里打开核显或多显示器。游戏和日常使用接 NVIDIA 显卡上的口。
